# CoreJava - Interview Preparation & Data Structures Practice

This repository is dedicated to practicing interview problems and implementing fundamental Data Structures and Algorithms in Java. It serves as a comprehensive interview preparation package with organized problem sets and detailed guides.

## Project Structure

The project is organized into several packages based on problem categories and difficulty levels:

### `src/test/java/programs/` - Core Algorithm Problems
*   **`array/`** (26 problems): Array manipulation, two-pointer techniques, sliding window, Kadane's algorithm
*   **`strings/`** (25 problems): String manipulation, palindromes, pattern matching, character operations
*   **`hashmaps/`** (10 problems): Frequency counting, anagrams, grouping problems
*   **`dp/`** (8 problems): Dynamic programming patterns, knapsack variants, sequence problems
*   **`stack/`** (8 problems): Stack operations, monotonic stacks, expression evaluation
*   **`heaps/`** (7 problems): Priority queue applications, K-element problems, scheduling
*   **`maths/`** (10 problems): Mathematical algorithms, number theory, digit manipulation
*   **`sorting/`** (3 problems): Sorting algorithms and variations
*   **`searching/`** (2 problems): Binary search and search algorithms
*   **`twopointers/`** (4 problems): Two-pointer technique applications
*   **`fileio/`** (9 problems): File I/O operations and utilities

### `src/test/java/advanced/` - Advanced Data Structures & Algorithms
*   **`backtracking/`** (7 problems): Combination generation, permutation problems, N-Queens
*   **`graphs/`** (14 problems): DFS/BFS, topological sort, shortest path, Union-Find
*   **`trees/`** (20 problems): Tree traversals, BST operations, path problems, LCA
*   **`linkedlist/`** (9 problems): Linked list manipulation, reversal, cycle detection
*   **`intervals/`** (5 problems): Interval merging, scheduling, sweep line
*   **`bitmanipulation/`** (6 problems): XOR operations, bit counting, bit manipulation
*   **`trie/`** (5 problems): Prefix tree implementation, word dictionary problems

### `src/test/java/datastructures/` (4 items)
*   Core data structure implementations

### `src/test/java/oldprograms/` - Legacy Practice Problems
*   **`LeetCode/`** (23 items): LeetCode problem solutions
*   **`Linkedin/`** (73 items): LinkedIn interview preparation problems
*   **`Notion/`** (8 items): Practice problems from various sources

### Documentation
Each folder contains a `GUIDE.md` file with:
*   Problem categorization and difficulty levels
*   Time/space complexity analysis
*   Key techniques and patterns
*   Interview preparation checklists
*   Common interview questions

## Technologies Used

*   **Language**: Java
*   **Build Tool**: Maven
*   **Testing Framework**: TestNG (used for validating solutions with different test cases)

## How to Use

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/[your-username]/CoreJava.git
    ```
2.  **Open in IDE**: Import the project as a Maven project in IntelliJ IDEA or your preferred IDE.
3.  **Run Tests**: You can run individual test files or all tests using Maven:
    ```bash
    mvn test
    ```
